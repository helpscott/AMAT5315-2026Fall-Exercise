# Repository Guidelines

This repository contains the weekly exercises for AMAT5315 (2026 Fall).

## Layout

Weekly exercises live in `week1/`, `week2/`, `week3/`, and so on. New work
for week N belongs in `weekN/`. For example, the Week 3 exercise belongs in
`week3/`.

## Working agreement

- Read the specification for the relevant week before changing code.
- Keep tests beside the weekly exercise and run them before committing.
- Preserve the instructional Git history, including deliberate red and green
  test states.
- Never add passwords, access tokens, service keys, or private notes because
  this repository is public.
